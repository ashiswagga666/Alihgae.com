## 📖 Tentang Alihgae.com

> **"Alihgae"** — nama yang mungkin bikin orang penasaran, tapi websitenya bikin orang langsung ngerti.

**Alihgae.com** adalah platform lowongan kerja modern yang dirancang khusus untuk ekosistem kerja Indonesia. Dibuat dengan semangat ~~dan air mata~~ dan dedikasi penuh, platform ini menghubungkan **pencari kerja** dengan **perusahaan terpercaya** dalam satu antarmuka yang bersih, cepat, dan responsif.

### Kenapa Alihgae?

| Masalah | Solusi Alihgae |
|---------|----------------|
| Lowongan kerja tersebar di mana-mana | Semua terpusat di satu platform |
| Info lowongan sering tidak lengkap | Detail posisi, kualifikasi & cara melamar tersedia jelas |
| Susah cari kerja sesuai lokasi | Filter berdasarkan kota & bidang kerja |
| HRD repot posting di banyak tempat | Satu dashboard untuk kelola semua iklan lowongan |


### 🔍 Pencarian Cerdas
Temukan pekerjaan impian dengan filter posisi, lokasi, jenis kerja (WFH/WFO/Hybrid), dan bidang industri. Tidak perlu scroll ratusan halaman!

### 📢 Pasang Iklan Lowongan
Perusahaan dapat mendaftar, membuat profil, dan langsung memposting lowongan dalam hitungan menit. Fitur manajemen iklan yang intuitif tanpa perlu keahlian teknis.

### 🏢 Halaman Profil Perusahaan
Setiap perusahaan punya halaman profil sendiri — lengkap dengan deskripsi, industri, ukuran perusahaan, dan semua lowongan aktif mereka.

### 📄 Detail Lowongan Lengkap
Tidak ada lagi lowongan misterius. Setiap iklan wajib mencantumkan deskripsi pekerjaan, kualifikasi, kisaran gaji (opsional), dan langkah-langkah melamar yang jelas.

## 🚀 Instalasi & Setup

### Prerequisites

Pastikan sudah terinstall:
- PHP >= 8.1
- Composer
- Node.js & NPM
- MySQL

### Langkah Instalasi

```bash
# 1. Clone repositori
git clone https://github.com/ashiswagga666/alihegae.git
cd alihegae

# 2. Install dependencies PHP
composer install

# 3. Install dependencies Node
npm install

# 4. Copy file environment
cp .env.example .env

# 5. Generate application key
php artisan key:generate

# 6. Konfigurasi database di .env
DB_DATABASE=alihgae
DB_USERNAME=root
DB_PASSWORD=

# 7. Jalankan migrasi & seeder
php artisan migrate --seed

# 8. Build assets
npm run dev

# 9. Jalankan server
php artisan serve
```

Buka browser dan akses `http://localhost:8000` 🎉
